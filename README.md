# 💰 Terminal Expense Tracker

A lightweight, CLI-based Python application designed to help you track personal expenses, categorize spending, and maintain persistent storage using JSON.

---

## 📌 Features

- **Interactive Menu:** Simple terminal interface for seamless navigation.
- **Data Validation:** Prevents invalid entries (empty descriptions or non-numeric/negative amounts).
- **Categorization:** Categorize expenses (Food, Transportation, Entertainment, Utilities, Other).
- **Persistent Storage:** Saves and loads your data automatically to `expenses.json`.
- **Expense Insights:** View a full log of transactions or summarize spending broken down by category.

---

## 🛠️ Requirements & Prerequisites

- **Python:** Python 3.6 or higher.
- **Dependencies:** Standard library only (`json`, `os`, `datetime`). No external packages required.

---
